# AI-Agents-Learning

Hand-written practice project for learning the Strands Agents SDK (TypeScript).
Reference: https://github.com/hireupau/architecture-examples

## Setup

```bash
bun install
cp .env.example .env   # fill in a provider
bun run dev
```

## Learning path

Tick off as you go; keep notes per step in `notes/`.

- [ ] 1. Single agent + local tool (`strands-demo`)
- [ ] 2. MCP tool over stdio
- [ ] 3. Structured output + two-agent pipeline
- [ ] 4. Observability (`strands-langfuse-demo`)
- [ ] 5. JWT-as-tool-argument auth (`strands-booking-auth`)
- [ ] 6. Sessions + credential injection (`strands-helpdesk-memory`)
- [ ] 7. OAuth token lifecycle (`strands-oauth-lifecycle`)
